# ☕ KopiDanNyemil

**KopiDanNyemil** adalah aplikasi mobile berbasis Android yang dikembangkan menggunakan bahasa pemrograman **Kotlin** dan **Android Studio**. Aplikasi ini dirancang untuk memudahkan pengguna memesan berbagai menu kopi dan cemilan favorit dengan antarmuka yang ramah pengguna (*user-friendly*) serta bernuansa hangat dan estetik.

---

## ✨ Fitur Utama

- **Dynamic Name Greeting (SharedPreferences)**: Nama pengguna yang dimasukkan pada halaman *Profile* akan disimpan secara permanen di memori lokal dan otomatis menyapa pengguna di halaman *Home*, *Order*, maupun halaman *Confirmation*.
- **Katalog Menu Lengkap & Scrollable**: Menampilkan berbagai pilihan menu makanan dan minuman (seperti Kopi Susu Gula Aren, Donat Cokelat, Sourdough Loaf, Cappuccino, dan Matcha Latte) yang dibungkus dalam *ScrollView* yang halus.
- **Navigasi Antar Halaman yang Mulus**: Dilengkapi dengan *Bottom Navigation Bar* (Home, Order, Profile) yang konsisten di setiap halaman utama.
- **Halaman Konfirmasi Pesanan**: Memberikan umpan balik instan kepada pengguna setelah melakukan pemesanan lengkap dengan sapaan nama personal.

---

## 🛠️ Teknologi yang Digunakan

- **Bahasa Pemrograman**: Kotlin
- **IDE**: Android Studio
- **UI Framework**: XML Layout (ConstraintLayout, RelativeLayout, LinearLayout, ScrollView)
- **Penyimpanan Lokal**: SharedPreferences
- **Kontrol Versi**: Git & GitHub (`lynrlla/KopiDanNyemil`)
